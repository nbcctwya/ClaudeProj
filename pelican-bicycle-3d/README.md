# 3D 鹈鹕骑自行车 🐦🚲

用 [three.js](https://threejs.org/) 做的 3D 小场景：一只白鹈鹕骑着自行车，沿着草地上的环形小路一圈一圈地骑。

## 运行

浏览器的 ES 模块不能直接从 `file://` 加载，需要起一个本地静态服务器：

```bash
cd pelican-bicycle-3d
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。three.js 通过 CDN（cdn.jsdelivr.net）加载，需要联网。

## 操作

| 操作 | 效果 |
| --- | --- |
| 鼠标左键拖动 | 旋转视角 |
| 滚轮 | 缩放 |
| 右键拖动 | 平移 |
| 空格 / 「暂停」按钮 | 暂停 / 继续 |
| B / 「按铃」按钮 | 按车铃（鹈鹕会开心地抬头） |
| 速度滑块 | 调节骑行速度 |
| 「跟随镜头」 | 开启时相机跟着鹈鹕移动 |

## 实现要点

- 所有模型都用 three.js 的基础几何体拼出来，没有外部模型文件。
- **自行车**：车轮按行驶距离滚动，曲柄按齿比转动，脚踏始终保持水平。
- **鹈鹕的腿**：两段式 IK（反向运动学），每帧根据脚踏位置算出膝盖位置，所以腿会真的跟着踩踏板。
- **翅膀**：从肩膀伸到车把上，像手一样握住把手。
- 过弯时整车向圆心倾斜，头部随踩踏轻轻点头，喉囊会微微晃动。
- 车筐里还有一条鱼。

## 文件
