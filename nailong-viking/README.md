# 奶龙 · 维京突击 (Nailong Viking Strike)

一款网页版竖版弹幕射击小游戏：**奶龙**戴上维京牛角头盔，驾驶龙首长船改装的**维京战机**，
迎击开着橘子战机、温泉澡盆、生菜轰炸机来抢奶的**水豚噜噜**大军。

所有角色和战机都是用 Canvas 代码画出来的，音效和背景音乐用 WebAudio 实时合成，
没有任何图片或音频文件，也不需要构建。

## 怎么玩

直接用浏览器打开 `index.html` 即可（手机、电脑都可以）。

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动（自动射击） | 鼠标 / WASD / 方向键 | 手指在屏幕任意处拖动 |
| 精准慢速（显示判定点） | 按住 Shift | — |
| 龙吼（清屏炸弹） | 空格 / X | 双击屏幕或右下角按钮 |
| 暂停 / 静音 | P / M | 右上角按钮 |

## 玩法要点

- **奶瓶**：火力升级（共 5 级），3 级起会自动甩出追踪的维京飞斧，5 级加上龙息火球。
- **维京盾**：10 秒护盾，一圈盾牌会挡掉碰到的子弹。
- **号角**：龙吼 +1。龙吼会清掉全屏子弹，并对所有敌人造成伤害。
- **奶龙头像**：1UP。
- 被击落的噜噜会**情绪稳定地跳伞**，飞过去接住能拿额外分数。
- 连续击落会累积**连击倍率**，最高 ×4。
- 每关约 55 秒后，Boss **噜噜大帝**坐着木桶温泉堡垒登场；它头上的橘子会随血量一个个掉下来，可以接住加分。
- 四个关卡主题循环出现：峡湾晨曦 → 冰川海域 → 橘子群岛 → 极光之夜，难度逐关上升。

## 调试参数

- `index.html?boss`：开局直接进入 Boss 战
- `index.html?stage=3`：从第 3 关开始

## 文件结构

```
index.html   页面与界面
style.css    界面样式
sprites.js   奶龙、水豚噜噜、战机、道具的 Canvas 绘制（启动时预渲染）
audio.js     WebAudio 合成音效与背景音乐
game.js      游戏主循环、敌人 AI、弹幕、关卡流程
```
